# Todo List

Простое консольное приложение для управления задачами на Java.
Программа позволяет добавлять задачи, просматривать их,
изменять статус и удалять задачи. Все задачи сохраняются в текстовый файл, поэтому после перезапуска программы они загружаются обратно.

## Возможности
* Добавление новой задачи
* Просмотр всех задач
* Изменение статуса задачи
* Удаление задачи по ID
* Сохранение задач в файл
* Загрузка задач при запуске программы

У каждой задачи есть:
* ID
* Название
* Статус

Доступные статусы:

* `NEW`
* `IN_PROGRESS`
* `DONE`
* 
## Структура проекта
```text
src/
├── Main.java
├── Task.java
├── TaskStatus.java
├── TaskManager.java
└── FileStorage.java
tasks.txt
README.md
```

### Назначение классов
* `Main` - меню программы и взаимодействие с пользователем.
* `Task` - объект одной задачи.
* `TaskStatus` - доступные статусы задач.
* `TaskManager` - добавление, удаление, поиск и изменение задач.
* `FileStorage` - сохранение и загрузка задач из файла.
* 
## Запуск
Для запуска нужен **Java 7 или новее**.

1. Открыть проект в IntelliJ IDEA.
2. Открыть `Main.java`.
3. Запустить метод `main`.
4. Использовать меню в консоли.

При запуске программа автоматически загружает задачи из `tasks.txt`.
При выходе задачи автоматически сохраняются в файл.

## Формат файла
Задачи хранятся в `tasks.txt`.

Пример:

```text
1|Learn Java|DONE
2|Learn Spring|IN_PROGRESS
3|Make Todo List|NEW
```
Формат:

```text
ID|Название|Статус
```
